# SERPy 0.1.0 Beta 1

First private, installable SERPy beta for the registered internal test Mac.

## Included

- Native macOS menu-bar companion using owner-supplied SERP branding.
- Free on-device dictation with no assistant engine, API key, or network
  dependency.
- Configurable toggle shortcut, defaulting to `Option-Space`.
- Press once to record, press again to finish and insert, or press Escape to
  cancel.
- Durable Last Dictation recovery and conservative cross-application text
  delivery.
- Optional explicitly invoked local screen guidance and cursor companion.
- Developer ID signed, notarized, stapled DMG with checksum and manifest.
- Shortcut isolation fix so unrelated `Command-Space` launchers retain their
  complete keyboard cycle.

## Beta limits

- Validated only on the registered internal test Mac.
- Cross-application dictation coverage remains incomplete; unsupported or
  unconfirmed destinations retain recoverable text.
- The final human Alfred `Command-Space` check remains an explicit acceptance
  observation.
- No automatic updater, public support promise, or public distribution claim.
