# Superwhisper product reference

- Saved: 2026-09-04
- Product landing page: https://superwhisper.com/
- Product introduction: https://superwhisper.com/docs/get-started/introduction
- Installed oracle: `/Applications/superwhisper.app`
- Intended use: Dictation behavior and product-surface reference for serpy

The landing page describes the primary flow as selecting another application,
pressing Option–Space, speaking, and receiving text in that application. It
markets support for Slack, Gmail, and other applications.

The introduction describes three stages: Dictation, Transcription, and Smart
Processing. It documents voice-to-text modes, optional processing modes,
language support, local and cloud models, file transcription, and initial setup.

For Version 1, serpy uses only the existing local Dictation behavior as the
required product reference. Licensing, purchasing, onboarding redesign, custom
modes, cloud processing, file transcription, and full Settings parity remain
later work.

This page records public product claims. It is not source code and does not
establish Superwhisper implementation details.
